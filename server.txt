EXPERIMENT 4(a) – BITMAP CHECKPOINT FOR OBJECT/WINDOW

Question

Write a Java program to capture an image of a GUI object and compare it
with a baseline image.

Aim

To perform a bitmap checkpoint by comparing the current screenshot of a
GUI object with a previously saved baseline image.

Program: BitmapObjectCheckpoint.java

    import javax.swing.*;
    import javax.imageio.ImageIO;
    import java.awt.*;
    import java.awt.image.BufferedImage;
    import java.io.File;
    import java.io.IOException;

    public class BitmapObjectCheckpoint {
        public static void main(String[] args) throws Exception {
            JFrame frame = new JFrame("Bitmap Checkpoint Test");
            JTextField searchBox = new JTextField("Search here", 20);

            JPanel panel = new JPanel();
            panel.add(searchBox);
            frame.add(panel);

            frame.setSize(350, 120);
            frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
            frame.setLocationRelativeTo(null);
            frame.setVisible(true);

            Thread.sleep(1000);

            File folder = new File("Screenshots");
            if (!folder.exists()) {
                folder.mkdirs();
            }

            BufferedImage currentImage = new BufferedImage(
                    searchBox.getWidth(),
                    searchBox.getHeight(),
                    BufferedImage.TYPE_INT_RGB
            );

            Graphics2D g2 = currentImage.createGraphics();
            searchBox.paint(g2);
            g2.dispose();

            File currentFile = new File(folder, "current_searchbox.png");
            ImageIO.write(currentImage, "png", currentFile);

            System.out.println("Current screenshot saved:");
            System.out.println(currentFile.getAbsolutePath());

            File baselineFile = new File(folder, "baseline_searchbox.png");

            if (!baselineFile.exists()) {
                System.out.println("Baseline image not found.");
                System.out.println("Copy current_searchbox.png as baseline_searchbox.png");
            } else {
                boolean result = compareImages(baselineFile, currentFile);

                if (result) {
                    System.out.println("BITMAP CHECKPOINT: TEST PASS");
                    System.out.println("Images are identical.");
                } else {
                    System.out.println("BITMAP CHECKPOINT: TEST FAIL");
                    System.out.println("Images are different.");
                }
            }

            Thread.sleep(2000);
            frame.dispose();
        }

        public static boolean compareImages(File file1, File file2) throws IOException {
            BufferedImage image1 = ImageIO.read(file1);
            BufferedImage image2 = ImageIO.read(file2);

            if (image1 == null || image2 == null) {
                return false;
            }

            if (image1.getWidth() != image2.getWidth()
                    || image1.getHeight() != image2.getHeight()) {
                return false;
            }

            for (int x = 0; x < image1.getWidth(); x++) {
                for (int y = 0; y < image1.getHeight(); y++) {
                    if (image1.getRGB(x, y) != image2.getRGB(x, y)) {
                        return false;
                    }
                }
            }

            return true;
        }
    }

Output

First run:

    Current screenshot saved:
    .../Screenshots/current_searchbox.png
    Baseline image not found.
    Copy current_searchbox.png as baseline_searchbox.png

After copying the first screenshot to
Screenshots/baseline_searchbox.png, run again. If the images match:

    BITMAP CHECKPOINT: TEST PASS
    Images are identical.

Compile and run

    javac BitmapObjectCheckpoint.java
    java BitmapObjectCheckpoint

Important

filename before the comparison run. Exact pixel comparison can fail if

EXPERIMENT 4(b) – BITMAP CHECKPOINT FOR SCREEN AREA

Question

Write a Java program to capture a selected screen area of a GUI window
and compare it with a baseline image using pixel similarity.

Aim

To crop a screen area and calculate the percentage of matching pixels
between the current and baseline images.

Program: BitmapScreenAreaCheckpoint.java

    import javax.swing.*;
    import javax.imageio.ImageIO;
    import java.awt.*;
    import java.awt.image.BufferedImage;
    import java.io.File;
    import java.io.IOException;

    public class BitmapScreenAreaCheckpoint {
        public static void main(String[] args) throws Exception {
            JFrame frame = new JFrame("Bitmap Area Checkpoint");
            JPanel panel = new JPanel(new FlowLayout());

            panel.add(new JLabel("Google Search"));
            panel.add(new JTextField(25));
            panel.add(new JButton("Search"));

            frame.add(panel);
            frame.setSize(800, 600);
            frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
            frame.setLocationRelativeTo(null);
            frame.setVisible(true);

            Thread.sleep(1000);

            BufferedImage fullImage = new BufferedImage(
                    frame.getWidth(),
                    frame.getHeight(),
                    BufferedImage.TYPE_INT_RGB
            );

            Graphics2D g2 = fullImage.createGraphics();
            frame.paint(g2);
            g2.dispose();

            File folder = new File("SeleniumScreenshots");
            if (!folder.exists()) {
                folder.mkdirs();
            }

            int width = Math.min(800, fullImage.getWidth());
            int height = Math.min(600, fullImage.getHeight());

            BufferedImage currentArea = fullImage.getSubimage(0, 0, width, height);

            File currentFile = new File(folder, "current_google_area.png");
            ImageIO.write(currentArea, "png", currentFile);

            System.out.println("Current screenshot saved:");
            System.out.println(currentFile.getAbsolutePath());

            File baselineFile = new File(folder, "baseline_google_area.png");

            if (!baselineFile.exists()) {
                System.out.println("Baseline image not found.");
                System.out.println("Copy current_google_area.png as baseline_google_area.png");
            } else {
                BufferedImage baseline = ImageIO.read(baselineFile);
                double similarity = compareImages(baseline, currentArea);

                System.out.printf("Image Similarity: %.2f%%%n", similarity);

                if (similarity >= 95.0) {
                    System.out.println("BITMAP CHECKPOINT: TEST PASS");
                } else {
                    System.out.println("BITMAP CHECKPOINT: TEST FAIL");
                }
            }

            Thread.sleep(2000);
            frame.dispose();
        }

        public static double compareImages(BufferedImage img1, BufferedImage img2) {
            if (img1.getWidth() != img2.getWidth()
                    || img1.getHeight() != img2.getHeight()) {
                return 0.0;
            }

            long totalPixels = (long) img1.getWidth() * img1.getHeight();
            long samePixels = 0;

            for (int x = 0; x < img1.getWidth(); x++) {
                for (int y = 0; y < img1.getHeight(); y++) {
                    if (img1.getRGB(x, y) == img2.getRGB(x, y)) {
                        samePixels++;
                    }
                }
            }

            return (double) samePixels / totalPixels * 100.0;
        }
    }

    BITMAP CHECKPOINT: TEST PASS

EXPERIMENT 6 – DATABASE CHECKPOINT: CUSTOM CHECK

Question

Write a Java program to perform a custom database checkpoint by
validating a student’s pass/fail status based on marks.

Aim

To retrieve marks from a SQLite database and compare the calculated
status with the expected status.

Required dependency

Add SQLite JDBC to Maven:

    <dependency>
        <groupId>org.xerial</groupId>
        <artifactId>sqlite-jdbc</artifactId>
        <version>3.45.3.0</version>
    </dependency>

Program: DatabaseCheckpointCustomCheck.java

    import java.sql.Connection;
    import java.sql.DriverManager;
    import java.sql.PreparedStatement;
    import java.sql.ResultSet;
    import java.sql.SQLException;
    import java.sql.Statement;

    public class DatabaseCheckpointCustomCheck {
        static final String DB_URL = "jdbc:sqlite:student.db";

        public static void setupDatabase() throws SQLException {
            try (Connection conn = DriverManager.getConnection(DB_URL);
                 Statement stmt = conn.createStatement()) {

                stmt.execute("CREATE TABLE IF NOT EXISTS students ("
                        + "id INTEGER PRIMARY KEY, "
                        + "name TEXT, "
                        + "marks INTEGER)");

                stmt.executeUpdate("DELETE FROM students");

                stmt.executeUpdate("INSERT INTO students VALUES (1, 'Amit', 78)");
                stmt.executeUpdate("INSERT INTO students VALUES (2, 'Neha', 45)");
                stmt.executeUpdate("INSERT INTO students VALUES (3, 'Ravi', 92)");
            }
        }

        public static boolean customCheckpoint(
                int studentId, String expectedStatus) throws SQLException {

            String sql = "SELECT marks FROM students WHERE id = ?";

            try (Connection conn = DriverManager.getConnection(DB_URL);
                 PreparedStatement ps = conn.prepareStatement(sql)) {

                ps.setInt(1, studentId);

                try (ResultSet rs = ps.executeQuery()) {
                    if (!rs.next()) {
                        System.out.println("FAIL: No record found for id " + studentId);
                        return false;
                    }

                    int marks = rs.getInt("marks");
                    String actualStatus = (marks >= 50) ? "Pass" : "Fail";

                    if (actualStatus.equalsIgnoreCase(expectedStatus)) {
                        System.out.println("PASS: Student " + studentId
                                + " status = " + actualStatus
                                + " (Custom check matched)");
                        return true;
                    } else {
                        System.out.println("FAIL: Student " + studentId
                                + " expected " + expectedStatus
                                + ", got " + actualStatus);
                        return false;
                    }
                }
            }
        }

        public static void main(String[] args) throws SQLException {
            setupDatabase();

            customCheckpoint(1, "Pass");
            customCheckpoint(2, "Fail");
            customCheckpoint(3, "Pass");
        }
    }

Output

    PASS: Student 1 status = Pass (Custom check matched)
    PASS: Student 2 status = Fail (Custom check matched)
    PASS: Student 3 status = Pass (Custom check matched)

Run

Run from Eclipse after adding the SQLite JDBC dependency and updating
the Maven project.

Program: BatchWithParams.java

    public class BatchWithParams {
        static void testOperation(int a, int b, char op, int expected) {
            int result;

            switch (op) {
                case '+':
                    result = a + b;
                    break;
                case '-':
                    result = a - b;
                    break;
                case '*':
                    result = a * b;
                    break;
                default:
                    System.out.println("Unsupported operator: " + op);
                    return;
            }

            String status = (result == expected) ? "PASS" : "FAIL";

            System.out.printf(
                    "Test: %d %c %d = %d (expected %d) -> %s%n",
                    a, op, b, result, expected, status
            );
        }

        public static void main(String[] args) {
            int[][] testCases = {
                    {2, 3, '+', 5},
                    {10, 4, '-', 6},
                    {3, 3, '*', 9},
                    {5, 5, '-', 1}
            };

            System.out.println("---- Batch Testing (With Parameters) ----");

            for (int[] tc : testCases) {
                testOperation(tc[0], tc[1], (char) tc[2], tc[3]);
            }
        }
    }

EXPERIMENT 8 – DATA-DRIVEN BATCH TESTING

Question

Write a Java program to perform data-driven batch testing using multiple
test data sets stored in a CSV file.

Aim

To read multiple test cases from a CSV file, execute them as a batch,
and display pass/fail counts.

Program: DataDrivenBatch.java

    import java.io.BufferedReader;
    import java.io.FileReader;
    import java.io.FileWriter;
    import java.io.IOException;
    import java.io.PrintWriter;

    public class DataDrivenBatch {
        public static double calculateDiscount(double price, String category) {
            switch (category) {
                case "electronics":
                    return price * 0.9;
                case "clothing":
                    return price * 0.8;
                default:
                    return price;
            }
        }

        public static void createCsvFile() throws IOException {
            try (PrintWriter pw = new PrintWriter(new FileWriter("batch_data.csv"))) {
                pw.println("Price,Category,ExpectedResult");
                pw.println("500,electronics,450");
                pw.println("300,clothing,240");
                pw.println("150,grocery,150");
                pw.println("1000,electronics,900");
            }
        }

        public static void dataDrivenBatch() throws IOException {
            System.out.println("---- Data Driven Batch Test ----");

            int passCount = 0;
            int failCount = 0;

            try (BufferedReader br = new BufferedReader(
                    new FileReader("batch_data.csv"))) {

                br.readLine(); // Skip header
                String line;

                while ((line = br.readLine()) != null) {
                    String[] parts = line.split(",");

                    double price = Double.parseDouble(parts[0].trim());
                    String category = parts[1].trim();
                    double expected = Double.parseDouble(parts[2].trim());

                    double actual = calculateDiscount(price, category);

                    if (Math.abs(actual - expected) < 0.000001) {
                        System.out.printf(
                                "PASS: %s, price=%.1f -> %.1f%n",
                                category, price, actual
                        );
                        passCount++;
                    } else {
                        System.out.printf(
                                "FAIL: %s, price=%.1f -> got %.1f, expected %.1f%n",
                                category, price, actual, expected
                        );
                        failCount++;
                    }
                }
            }

            System.out.println("\nBatch Summary: " + passCount
                    + " Passed, " + failCount + " Failed");
        }

        public static void main(String[] args) throws IOException {
            createCsvFile();
            dataDrivenBatch();
        }
    }

Output

    PASS: clothing, price=300.0 -> 240.0
    PASS: grocery, price=150.0 -> 150.0
    PASS: electronics, price=1000.0 -> 900.0

    Batch Summary: 4 Passed, 0 Failed

    javac DataDrivenBatch.java

Program: SilentModeTest.java

    import java.io.IOException;
    import java.util.logging.FileHandler;
    import java.util.logging.Logger;
    import java.util.logging.SimpleFormatter;

    public class SilentModeTest {
        static Logger logger = Logger.getLogger("SilentTestLogger");

        static void setupLogger() throws IOException {
            logger.setUseParentHandlers(false);

            FileHandler fh = new FileHandler("silent_test_log.txt");
            fh.setFormatter(new SimpleFormatter());

            logger.addHandler(fh);
        }

        static void testCase(String name, Object actual, Object expected) {
            if (actual.equals(expected)) {
                logger.info(name + ": PASS (actual=" + actual
                        + ", expected=" + expected + ")");
            } else {
                logger.severe(name + ": FAIL (actual=" + actual
                        + ", expected=" + expected + ")");
            }
        }

        public static void main(String[] args) throws IOException {
            setupLogger();

            testCase("Addition Test", 2 + 2, 4);
            testCase("Subtraction Test", 10 - 5, 5);
            testCase("Multiplication Test", 3 * 3, 10);
            testCase("String Test", "abc".toUpperCase(), "ABC");

            System.out.println(
                    "Batch execution completed silently. "
                    + "Check silent_test_log.txt for results."
            );

            for (java.util.logging.Handler handler : logger.getHandlers()) {
                handler.close();
            }
        }
    }

EXPERIMENT 10 – TEST CASE FOR CALCULATOR IN WINDOWS APPLICATION

Question

Write a Java program to test the Windows Calculator application by
performing an addition operation using the Robot class.

Aim

To automate keyboard input in Windows Calculator, perform 7 + 5, and
capture a screenshot of the result.

Program: CalculatorTest.java

    import java.awt.Rectangle;
    import java.awt.Robot;
    import java.awt.Toolkit;
    import java.awt.image.BufferedImage;
    import java.awt.event.KeyEvent;
    import javax.imageio.ImageIO;
    import java.io.File;

    public class CalculatorTest {
        public static void main(String[] args) throws Exception {
            // Open Windows Calculator
            Runtime.getRuntime().exec("calc.exe");
            Thread.sleep(2000);

            Robot robot = new Robot();
            robot.setAutoDelay(200);

            // Perform 7 + 5 = using keyboard input
            typeKey(robot, KeyEvent.VK_7);
            typeKey(robot, KeyEvent.VK_ADD);
            typeKey(robot, KeyEvent.VK_5);
            typeKey(robot, KeyEvent.VK_ENTER);

            Thread.sleep(1000);

            // Capture the complete screen
            Rectangle screenRect = new Rectangle(
                    Toolkit.getDefaultToolkit().getScreenSize()
            );

            BufferedImage capture = robot.createScreenCapture(screenRect);

            ImageIO.write(capture, "png", new File("calculator_result.png"));

            System.out.println("Test executed: 7 + 5 = 12");
            System.out.println(
                    "Screenshot saved as calculator_result.png. "
                    + "Compare visually to confirm the result is 12."
            );
        }

        static void typeKey(Robot robot, int keyCode) {
            robot.keyPress(keyCode);
            robot.keyRelease(keyCode);
        }
    }

Output

    Test executed: 7 + 5 = 12


Compile and run

    javac CalculatorTest.java
    java CalculatorTest
